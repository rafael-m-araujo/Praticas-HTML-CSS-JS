# 💻 Front-End Curso

Repositório criado para armazenar os exercícios, desafios e projetos desenvolvidos durante meus estudos de Desenvolvimento Front-End.

## 🚀 Sobre

Ao longo deste repositório, pratiquei conceitos fundamentais para construção de interfaces web, passando desde a estruturação de páginas com HTML até técnicas de responsividade e organização de layouts utilizando CSS.

O objetivo foi fortalecer a base em desenvolvimento web através da prática constante e da construção de pequenos projetos.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3

## 📚 Conteúdos Praticados

* Estrutura básica de páginas HTML
* Elementos semânticos
* Formulários
* Estilização com CSS
* Seletores e propriedades CSS
* Flexbox
* Responsividade
* Organização de layouts
* Boas práticas de estruturação
